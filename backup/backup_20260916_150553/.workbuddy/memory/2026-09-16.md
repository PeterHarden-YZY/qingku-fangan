# 2026-09-16 清库方案自动计算

## 数据口径重大修正（库龄数组问题）
- 库龄字段已改为数组：数组元素 = 《库存表》行（批次），每行自带 可用量+库龄(程序拉取)，按行 join 得到数量×库龄映射
- 清库表同名子model多关系行会导致库存重复计数（如 AMESD01B-F-US 6条各显示1，真实库存只有1件）→ 组件池必须按子model名合并去重
- 库存表有 7691 条（分页 2000 上限，必须翻页拉取）
- 对账：清库表 lookup 聚合值 vs 库存表行级聚合 = 0 差异
- 独立站团队库存全部在海外仓（390行），min(独立站,海外仓总量) 行级自动满足

## 修复的计算 bug
- 阶段四计提：BOM 1:1 下每个组件都有 ΔK 件未卖出（非按比例分摊，此前低估3倍）；未清库批次 = 消耗批次尾部（最年轻），FIFO 精确分配
- 写回语义：K>0 但本轮卖不掉 = 未清库(计提)，不是报废；只有物理长版剩余才写「报废」
